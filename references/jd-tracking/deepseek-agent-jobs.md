## 📋 职位列表

### 1. Agent 数据评测专家
- **文件**: [agent-data-evaluator.jpg](./agent-data-evaluator.jpg)
- **地点**: 杭州 / 北京
- **类型**: 全职

**核心要求**:
- 具备 Claude Code、Cursor、OpenClaw 等 AI 编程工具的重度使用经验
- 熟练掌握 Python，能独立编写数据处理、评测脚本
- 对大语言模型有基础认知，探索模型能力边界
- 多年工程开发经验，完成过大型项目

**加分项**:
- 前端开发经验（React/Vue）
- 大模型数据标注、评测体系设计经验

### 2. Agent 基础设施工程师
- **文件**: [agent-infrastructure-engineer.jpg](./agent-infrastructure-engineer.jpg)
- **地点**: 杭州 / 北京
- **类型**: 全职

**核心要求**:
- 前端开发经验，熟练掌握 JavaScript/TypeScript
- 熟悉 Python、Rust
- 熟悉 Docker、Kubernetes 等容器技术
- 熟悉 Claude Code、Cursor、Copilot 等 AI 编程工具

**加分项**:
- Agent 评测平台、轨迹回放或可视化工具开发经验
- 对大语言模型（LLM）有系统性认知
- 熟悉 Agent 交互协议与规范（MCP、Tool Use、Function Calling）
- 深度使用 Claude Code、Cursor 等 AI 编程工具

## 🔍 市场观察

### 关键信号

1. **AI 编程工具成为硬性要求**
   - Claude Code、Cursor、Copilot 被列为必备技能
   - 不再是"加分项"，而是基础门槛

2. **从"会用 AI"到"懂 AI"**
   - 需要对 LLM 有系统性认知
   - 理解 Context Window、Token 机制等核心概念
   - 具备高质量 Prompt 编写能力

3. **Agent 生态系统成为新战场**
   - MCP（Model Context Protocol）
   - Tool Use / Function Calling
   - Agent 评测体系

4. **全栈能力仍是基础**
   - TypeScript/Python/Rust
   - Docker/K8s 容器化
   - CI/CD、Git 工作流
