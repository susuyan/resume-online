# 简历优化设计文档

**日期**: 2026-03-30
**项目**: 简历深度重构优化
**设计者**: Claude Code

---

## 概述

对现有简历进行深度重构，解决信息密度不够、布局不醒目、亮点不突出、技能展示单调的问题。通过模块化设计和现代极简风格，突出 AI-Native 开发能力 + 端到端交付能力的差异化优势。

---

## 设计目标

### 核心定位
**突出差异化优势：** AI-Native 开发能力 + 端到端交付能力

### 改进目标
- ✅ 提升信息密度（参考 Milo Vex Resume 风格）
- ✅ 优化视觉层次（现代极简设计）
- ✅ 突出核心亮点（量化数据 + 具体成就）
- ✅ 改进技能展示（标签云形式，技术 + 软技能混合）

---

## 设计原则

**结构策略：** 能力优先型结构
- 快速展示核心能力
- 通过具体案例支撑
- 符合 ATS 系统筛选逻辑

**视觉风格：** 现代极简风
- 清晰的视觉层次
- 微妙的配色对比
- 充分的留白

**实施策略：** 渐进式优化
- 先调整信息骨架
- 模块化组合迭代
- 每步可验证效果

---

## 信息骨架结构（模块化）

### 模块 1：头部信息

**内容：**
```
余胜民
全栈软件交付工程师
电话 · 邮箱 · 微信 · GitHub

个人简介（1-2段）
```

**设计要求：**
- 姓名：大号粗体，视觉焦点
- 职位：中等字号，主色调（#1A365D）
- 联系方式：紧凑排列，用 `·` 分隔
- 个人简介：突出 AI-Native + 端到端交付优势，展现个性（参考 Milo Vex 风格）

**示例风格：**
> I build tools that help people think less about tooling. Spent the last two years making an AI write better code than me, then pretending that was the plan all along.

---

### 模块 2：核心优势（新增）

**内容：**
```
AI-Native (效率提升40%) · Full-Cycle (交付缩短30%) · High-Performance (10K+/秒)
```

**设计要求：**
- 卡片式设计，色块背景高亮
- 关键词 + 量化数据
- 用 `·` 分隔，紧凑排列
- 视觉醒目，一眼可见核心优势

**技术实现：**
- 在 `renderer.jsx` 中新增核心优势模块渲染
- 在 `build/index.css` 中新增卡片样式
- 在 `resume.md` 中提取核心优势数据

---

### 模块 3：EXPERIENCE（工作经历）

**内容结构：**
```
职位 — 公司
时间段
• 成就 1（量化 + 具体）
• 成就 2
• 成就 3
```

**设计要求：**
- 时间线形式，倒序排列
- 每段工作经历 3-4 个成就描述
- 使用动作动词开头（Architected、Delivered、Implemented、Integrated）
- 包含量化数据（效率提升 40%、支持 10,000+ 用户）

**优化重点：**
- 简化描述，突出影响力
- 删除笼统描述，增加具体细节
- 量化成果，用数据说话

---

### 模块 4：SKILLS（技能标签云）

**内容：**
```
技术1 · 技术2 · 技术3 · 软技能1 · 软技能2
```

**设计要求：**
- 标签云形式，用 `·` 分隔
- 混合技术栈 + 软技能
- 紧凑排列，高信息密度
- 不分组，扁平化展示

**技术栈示例：**
```
TypeScript · React · Python · Node.js · Docker · Claude Code · Cursor · 系统设计 · 快速交付 · 全栈思维
```

---

### 模块 5：EDUCATION（教育背景）

**内容：**
```
学历 — 学校
专业方向
```

**设计要求：**
- 简洁，不超过 2 行
- 可选添加专业方向或关键课程

## 视觉设计规范

### 配色方案（保持现有）

```json
{
  "primary": "#1A365D",      // 主色调 - 深蓝
  "secondary": "#2C5282",    // 次色调 - 中蓝
  "accent": "#C05621",       // 强调色 - 橙棕
  "text": "#2D3748",         // 正文色 - 深灰
  "lightGray": "#718096",    // 浅灰
  "border": "#E2E8F0"        // 边框色
}
```

**新增配色用途：**
- 核心优势卡片背景：`#EDF2F7`（HeaderBg）
- 核心优势卡片边框：`#E2E8F0`（Border）

---

### 字体排版

**层级设计：**
- **姓名**：1.8em，粗体，主色调
- **职位**：1.2em，中等粗细，主色调
- **联系方式**：0.9em，浅灰色
- **个人简介**：继承基础字号，行高 1.5
- **核心优势**：0.95em，粗体，主色调
- **工作经历标题**：1.1em，粗体，主色调，下边框
- **成就描述**：继承基础字号
- **技能标签**：继承基础字号，紧凑排列

---

### 间距布局

**模块间距：**
- 模块间：12px（保持现有 `sectionSpacing`）
- 核心优势模块：内边距 8px，外边距 12px

**内部间距：**
- 项目符号间距：6px（保持现有 `itemSpacing`）
- 核心优势标签间距：用 `·` 字符分隔，无需额外间距
